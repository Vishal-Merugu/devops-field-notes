# Swiss Minimalist design system

The journal uses a continuous grid of white, black, pale grey, and small red signals. Rules, shared edges, a narrow index rail, and restrained type carry hierarchy. Controls are square, keyboard-visible, and readable without color alone. Keep the page free of shadows, gradients, rounded cards, decorative motion, and invented content.

Authoritative CSS tokens live at the top of `src/styles.css` and use the `--dp-*` names from the brief. Host Grotesk is preferred with a system fallback. At 1050px the editorial grid simplifies; at 700px rails move above content and grids stack. Respect reduced-motion preferences.
